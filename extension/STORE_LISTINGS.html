1. Tăng Version trong package.json Mở extension/package.json (hiện đã nâng lên 1.1.0 và build sẵn trong .output/). Khi ra bản tiếp theo cần tăng tiếp, vì cả 3 store sẽ từ chối ZIP nếu trùng version đã phát hành.

📝 Mô Tả Ngắn (Summary / Short Description) Tối đa 132 ký tự (Hiện tại: 112 ký tự)
Tiện ích Side Panel cào tiểu thuyết mọi trang web, lọc sạch quảng cáo, đọc offline và xuất TXT, DOCX, PDF, EPUB.
📖 Mô Tả Chi Tiết (Detailed Description)
Novel Scraper là tiện ích mở rộng Side Panel thông minh giúp bạn trích xuất, làm sạch, lưu trữ và đọc tiểu thuyết mạng ngoại tuyến từ mọi website, đồng thời xuất sách sang TXT, DOCX, PDF, EPUB 3 và JSON một cách nhanh chóng và hoàn toàn riêng tư. ✨ CÁC TÍNH NĂNG NỔI BẬT: 1. ENGINE BÓC TÁCH 3 TẦNG (UNIVERSAL ENGINE): • Cấu hình tối ưu sẵn (Presets): Hỗ trợ mượt mà nhiều trang truyện phổ biến (Cổ Mộng, TruyệnFull, Tàng Thư Viện, Mê Truyện Chữ...), tự động quét mục lục phân trang nhiều lớp và AJAX. • Tự Động Nhận Diện (Heuristic Reader View): Phân tích cấu trúc DOM và mật độ đoạn văn để tự tìm nội dung chương trên mọi website lạ. • Chọn Vùng Bằng Chuột (Visual Element Picker): Rê chuột phát sáng phần tử và click để lưu CSS selector riêng cho từng tên miền. 2. LỌC VĂN BẢN SIÊU SẠCH (PURE TEXT SANITIZER): • Loại bỏ quảng cáo, iframe, ảnh/video rác, thẻ ẩn chống bot (honeypot) và ký tự tàng hình chống copy (\u200B-\u200D). • Chuẩn hóa Unicode tiếng Việt (NFC) chuẩn mực, không lỗi dấu. • Giải mã chữ bị xáo trộn (Deobfuscator), lọc watermark/re-up và hỗ trợ quy tắc Tìm & Thay thế (Find & Replace / Regex) tùy chỉnh. 3. GỘP & XUẤT ĐA ĐỊNH DẠNG (TXT · DOCX · PDF · EPUB · JSON): • TXT (UTF-8 BOM): Mở chuẩn trên Windows Notepad, Word và ứng dụng đọc trên điện thoại. • DOCX (Microsoft Word): Heading phân cấp chương, ngắt trang tự động (PageBreak) và căn lề in ấn. • PDF: Bố cục sách in sạch đẹp, đánh số trang tự động. • EPUB 3: Chuẩn sách điện tử quốc tế, tương thích Kindle, Kobo, Apple Books. • JSON & Tách tập ZIP: Xuất dữ liệu đầy đủ hoặc tự động chia tập (vd: 100 chương/tập) thành 1 file .zip. 4. CÀO LỊCH SỰ, THƯ VIỆN & TRÌNH ĐỌC OFFLINE: • Độ trễ ngẫu nhiên (1.5s - 3s), tự động thử lại khi gặp giới hạn tốc độ (429/503) và lưu tiến trình bền vững trong IndexedDB. • Tự động đồng bộ tab trình duyệt (Tab Auto-Sync), phát hiện và tải bù chương thiếu chỉ với 1 click. • Trình đọc Offline Reader tích hợp: 3 giao diện (Dark, Sepia, Light), chọn font Serif/Sans, chỉnh cỡ chữ và ghi nhớ tiến độ đọc. • Sao lưu & phục hồi toàn bộ thư viện qua file JSON. 5. GIAO DIỆN HIỆN ĐẠI & BẢO MẬT 100% CLIENT-SIDE: • Thiết kế kính mờ Glassmorphism (Shades of Blue) với Dark/Light Mode và chuyển đổi song ngữ Tiếng Việt / English tức thì. • Phím tắt mở nhanh: Alt + Shift + N. • Không máy chủ thu thập, không telemetry — toàn bộ dữ liệu nằm trên máy của bạn.

Novel Scraper - Web Novel Downloader & Reader
📝 Summary / Short Description Max 132 chars (Current: 115 chars)
Scrape web novels from any website in Side Panel. Clean text, read offline, and export to TXT, DOCX, PDF, and EPUB.
📖 Detailed Description
Novel Scraper is a privacy-first Side Panel browser extension designed to help book lovers extract, clean, read offline, and export web novels from any website into TXT, DOCX, PDF, EPUB 3, and JSON formats. ✨ KEY FEATURES: 1. UNIVERSAL 3-TIER SCRAPING ENGINE: • Built-in Presets: Ready-to-use rules for popular novel platforms with multi-page and AJAX table-of-contents scanning. • Heuristic Reader View: Automatically detects chapter titles and main story content on unfamiliar websites using DOM and paragraph-density analysis. • Visual Element Picker: Hover to highlight elements and click to save custom CSS selectors per domain. 2. PURE TEXT SANITIZER PIPELINE: • Strips ads, banners, scripts, iframes, hidden honeypot elements, and zero-width anti-copy characters (\u200B-\u200D). • Standardized Unicode normalization (NFC) for clean typography. • Text deobfuscator, custom watermark keyword filtering, and Find & Replace / Regex rules. 3. MULTI-FORMAT EXPORT (TXT · DOCX · PDF · EPUB · JSON): • TXT (UTF-8 with BOM): Clean plain text with no encoding glitches. • DOCX (Microsoft Word): Structured headings, automatic page breaks between chapters, and print margins. • PDF: Print-ready book layout with automatic page numbering. • EPUB 3: Standard e-book archive compatible with Kindle, Kobo, and Apple Books. • JSON & Split-Volume ZIP: Export structured backups or automatically split long novels into multi-volume .zip bundles. 4. POLITE CRAWLING & BUILT-IN OFFLINE READER: • Adaptive jitter delays (1.5s - 3.0s), exponential backoff on HTTP 429/503, and persistent IndexedDB queue. • Automatic browser Tab Auto-Sync and 1-click missing chapter detection & re-download. • Integrated Offline Reader with Dark, Sepia, and Light themes, Serif/Sans fonts, adjustable font size, and reading progress memory. • 1-click JSON Backup & Restore for your entire offline library and site rules. 5. GLASSMORPHISM UI & ZERO TELEMETRY: • Shades of Blue frosted glass Side Panel UI with Dark/Light modes and instant English / Vietnamese language switching. • Quick shortcut: Alt + Shift + N. • 100% client-side: zero tracking, zero analytics, zero remote servers.
🛡️ PRIVACY PRACTICES & PERMISSION JUSTIFICATIONS (CHROME WEB STORE)
Sao chép chính xác vào tab Privacy practices trên Chrome Web Store Developer Dashboard (bao gồm quyền tabs mới trong wxt.config.ts):
🎯 Single purpose description * Tối đa 1000 ký tự
Novel Scraper is a side panel utility designed solely to allow users to extract, clean, read offline, and export web novel chapters from novel websites into TXT, DOCX, PDF, EPUB, and JSON files locally in their browser.
💾 storage justification *
Required to store user preferences (theme, language, polite crawling delay, custom watermark filters, replacement rules) and maintain the offline novel library and site rules locally in browser storage and IndexedDB.
📑 activeTab justification *
Required to access the active tab's novel webpage only when the user explicitly triggers chapter detection, TOC scanning, or the visual element picker.
🗂️ tabs justification * QUYỀN MỚI TRONG WXT.CONFIG
Required to detect active tab switches/updates so the Side Panel automatically syncs with the novel currently viewed by the user, and to query/message the user's open novel tab for chapter extraction and same-origin page fetching during user-initiated crawls.
⚡ scripting justification *
Required to inject the visual element picker overlay and reader view extraction logic into the active web novel page upon user request.
📥 downloads justification *
Required to allow users to export and download compiled novel files (.txt, .docx, .pdf, .epub, .json, or .zip) and JSON library backups to their local computer.
🖥️ sidePanel justification *
Required to display the extension's primary user interface and built-in offline reader inside the browser's side panel while the user browses novel pages.
🌐 Host permission (<all_urls>) justification *
Required because web novels are hosted across thousands of independent domains. Users need to extract chapters from any novel reading website they visit and choose to scrape.

🧪 Test Instructions (Hướng dẫn cho Chrome Reviewer)
Reviewer Test Instructions: 1. Click the Novel Scraper toolbar icon (or press Alt+Shift+N) to open the Side Panel. 2. Navigate to any web novel page (chapter page or table of contents). 3. In the Scraper tab: - Click "Auto Detect" to extract the chapter title and main text using heuristic reader view. - Click "Pick with Mouse" to highlight DOM elements on the page and click to select a custom container (press ESC to cancel). - Click "Scan TOC" to collect chapter links, then "Start Crawl" to save chapters locally in IndexedDB. 4. In the Library tab: - Open the built-in Offline Reader or export the saved novel to TXT, DOCX, PDF, EPUB, or JSON. 5. Note on "tabs" permission: Used solely to auto-sync the Side Panel with the currently active novel tab and delegate same-origin chapter fetches to an open matching tab when triggered by the user. All data stays 100% local in the browser; no remote code or analytics are used.

📖 Description
Novel Scraper is a privacy-first Sidebar browser extension designed to help book lovers extract, clean, read offline, and export web novels from any website into TXT, DOCX, PDF, EPUB 3, and JSON formats. ✨ KEY FEATURES: 1. UNIVERSAL 3-TIER SCRAPING ENGINE: • Built-in Presets: Ready-to-use rules for popular novel platforms with multi-page and AJAX table-of-contents scanning. • Heuristic Reader View: Automatically detects chapter titles and main story content on unfamiliar websites using DOM and paragraph-density analysis. • Visual Element Picker: Hover to highlight elements and click to save custom CSS selectors per domain. 2. PURE TEXT SANITIZER PIPELINE: • Strips ads, banners, scripts, iframes, hidden honeypot elements, and zero-width anti-copy characters (\u200B-\u200D). • Standardized Unicode normalization (NFC) for clean typography. • Text deobfuscator, custom watermark keyword filtering, and Find & Replace / Regex rules. 3. MULTI-FORMAT EXPORT (TXT · DOCX · PDF · EPUB · JSON): • TXT (UTF-8 with BOM): Clean plain text with no encoding glitches. • DOCX (Microsoft Word): Structured headings, automatic page breaks between chapters, and print margins. • PDF: Print-ready book layout with automatic page numbering. • EPUB 3: Standard e-book archive compatible with Kindle, Kobo, and Apple Books. • JSON & Split-Volume ZIP: Export structured backups or automatically split long novels into multi-volume .zip bundles. 4. POLITE CRAWLING & BUILT-IN OFFLINE READER: • Adaptive jitter delays (1.5s - 3.0s), exponential backoff on HTTP 429/503, and persistent IndexedDB queue. • Automatic browser Tab Auto-Sync and 1-click missing chapter detection & re-download. • Integrated Offline Reader with Dark, Sepia, and Light themes, Serif/Sans fonts, adjustable font size, and reading progress memory. • 1-click JSON Backup & Restore for your entire offline library and site rules. 5. GLASSMORPHISM UI & ZERO TELEMETRY: • Shades of Blue frosted glass Sidebar UI with Dark/Light modes and instant English / Vietnamese language switching. • Quick shortcut: Alt + Shift + N. • 100% client-side: zero tracking, zero analytics, zero remote servers.

💬 Notes to Reviewer (Bắt buộc giải thích build & quyền tabs)
Dear AMO Reviewer, This update keeps all processing 100% client-side with zero telemetry or remote code execution ("data_collection_permissions": { "required": ["none"] }). Note on permissions: - "tabs" is used solely to sync the sidebar UI when the user switches tabs and to communicate with the active/matching novel tab during user-initiated TOC scanning or chapter fetching. To reproduce the exact Firefox build from the uploaded sources.zip: 1. Ensure Node.js v20+ (tested on v22 LTS) and npm v10+ are installed. 2. Unpack novel-scraper--sources.zip and run: npm ci 3. Run the automated test suite: npm test 4. Build the Firefox MV3 extension: npm run build:firefox 5. The identical build output is generated in .output/firefox-mv3/ How to test: 1. Open any web novel chapter or table-of-contents page. 2. Open the Novel Scraper sidebar (toolbar icon or Alt+Shift+N). 3. Click "Auto Detect" or "Pick with Mouse" to extract content, or "Scan TOC" to gather chapters. 4. Export to TXT, DOCX, PDF, EPUB, or JSON, or open the built-in Offline Reader in the Library tab.
